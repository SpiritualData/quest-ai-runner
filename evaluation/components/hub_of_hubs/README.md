# hub_of_hubs

QAR's binding of the hub scorer: the metric of `use-open-source-hubs` (sub-metric QME9 of `qar_overall`). The registry, the eight
checks and the scoring live in the public [ai-hub-of-hubs-structure](https://github.com/SpiritualData/ai-hub-of-hubs-structure)
repository; this folder only says how QAR meets them.

| File | Role |
|---|---|
| `__init__.py` | imports the hub like the esoi library: installed, or the sibling checkout `../ai-hub-of-hubs-structure` put on the path |
| `binding.py` | the seat bindings: `esoi/hub_seats.csv` says which QAR solution fills each area; builds the hub's `Binding` |
| `probes.py`, `fake_hub.py` | one probe per area proving a fake hub can be added through that area's configuration entry |
| `impls/registry_scan.py` | the live arm: the hub's `evaluate` on QAR's bindings |
| `broken/vendor_grep.py` | the floor: grep for vendor names |
| `score.py`, `render_docs.py`, `cases.json` | thin hand-offs to the hub (cases are generated by `python -m ai_hub_of_hubs.cases`) |

```
esoi run hub_of_hubs --impl registry_scan --record                  # the live reading
esoi run hub_of_hubs --impl hub_of_hubs.broken.vendor_grep:build    # the floor
python3 evaluation/components/hub_of_hubs/render_docs.py            # rewrite the generated table in docs/hub-of-hubs.md
.venv/bin/python3 -m pytest evaluation/components/test_hub_of_hubs.py
```
